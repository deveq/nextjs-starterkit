# git:commit 커맨드

사용자가 제공한 커밋 메시지: $ARGUMENTS
만약 사용자가 제공한 커밋 메시지가 없다면 아래의 절차에 따라 분석 후 적절한 커밋 메시지를 지정한다.

## 절차

1. **변경사항 분석**
   - 현재 git 상태와 변경 내용을 확인합니다
   - 스테이징된 파일과 미스테이징 파일을 파악합니다

2. **메시지 검증**
   - 사용자가 제공한 메시지가 실제 변경사항과 일치하는지 확인합니다
   - 메시지가 일반적인 커밋 메시지 형식을 따르는지 확인합니다

3. **검증 결과**
   - ✓ 적절한 경우: 바로 커밋을 생성합니다
   - ✗ 부적절한 경우: 문제점을 지적하고 더 적절한 메시지를 제안합니다
   - 사용자의 확인 후 커밋을 진행합니다

4. **커밋 생성**
   - 최종 승인된 메시지로 커밋을 생성합니다
   - 커밋 완료 후 로그를 표시합니다
